# Мои чеки — экспорт и аналитика

**Приложение для Windows: чеки ФНС, расходы по категориям и Excel за выбранные годы.**

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![Windows](https://img.shields.io/badge/Windows-10%2F11-0078D4)
![Excel](https://img.shields.io/badge/Экспорт-.xlsx-217346)

Загружайте чеки из «Мои чеки онлайн», храните историю локально и получайте подробные отчёты. Повторная загрузка всей базы не требуется.

## Возможности

- Загрузка ФНС за выбранный период, поиск и фильтр по продавцу.
- **Выбор годов Excel:** отдельные годы, диапазоны или вся история.
- По умолчанию — **текущий календарный год и два предыдущих**: в 2026 году это 2024–2026, в 2027 — 2025–2027.
- Сводка, статистика по категориям, продуктовый дашборд, чеки, товары и листы продавцов.
- Настройка категорий и магазинов, включения/исключения товаров, ручные покупки.
- Импорт и сопоставление возвратов Ozon; подтверждённые возвраты уменьшают расходы.
- Исключение отмеченных дубликатов маркетплейсов и авансовых чеков.
- Синхронизация из командной строки и ежедневное задание Windows.

## Быстрый старт

1. Откройте [последний релиз](https://github.com/Wolfhander/moi-cheki-exporter/releases/latest).
2. Скачайте `MoiCheki-windows-x64.zip` и распакуйте архив.
3. Запустите `MoiCheki.exe`. Установка Python для готовой сборки не нужна.
4. При обновлении закройте программу и замените исполняемый файл. Пользовательские данные хранятся отдельно.

Сборка предназначена для Windows 10/11 x64 и не подписана цифровым сертификатом.

## Запуск из исходников

Нужен Python 3.10+ с Tkinter (входит в обычный установщик Python для Windows).

```powershell
git clone https://github.com/Wolfhander/moi-cheki-exporter.git
cd moi-cheki-exporter
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Как пользоваться

### Авторизация и загрузка

Нажмите **«Войти через Госуслуги»**: откроется системный браузер с `lkdr.nalog.ru`. После входа откройте `F12` → **Application / Storage** → **Local Storage** → `https://lkdr.nalog.ru`. Скопируйте `refresh-token` и `device-id` в диалог программы. Его можно открыть кнопкой **«Ввести токен»**.

Пароль Госуслуг программе не нужен. Токены хранятся в локальной базе; обращайтесь с ними как с паролями.

На вкладке **«Загрузка»** задайте даты и нажмите **«Загрузить чеки»**. Уже сохранённые чеки пропускаются. На вкладке **«Чеки»** доступны поиск и фильтр продавца.

### Категории и дополнительные расходы

Задайте категории и привязки магазинов в настройках. Для продуктового дашборда настройте магазины категории **«Продукты»**, включения и исключения товаров. Ручные покупки и возвраты добавляются через соответствующие вкладки.

### Выбор годов Excel

На вкладке **«Экспорт»** заполните **«Годы для экспорта»**:

| Значение | Результат |
| --- | --- |
| `2024, 2026` | Два отдельных года |
| `2024–2026` | Все годы диапазона включительно |
| `2022, 2024–2026` | Отдельный год и диапазон |
| **«Последние 3 года»** | Текущий год и два предыдущих |
| **«Все годы»** | Вся история |

Выберите параметры и нажмите **«Экспортировать в Excel»**.

**Один период применяется ко всей книге:** чекам, товарам, продавцам, статистике, категориям и продуктовому дашборду. Ручные покупки фильтруются по дате покупки, возвраты — по дате заявления. Выбор годов не удаляет данные из базы и не меняет период загрузки ФНС.

При выборе конкретных лет записи без корректной даты исключаются. Если данных за период нет, программа предложит выбрать другой период. Пустой продуктовый лист не включается в книгу.

## Хранение и резервные копии

```text
%USERPROFILE%\.moi_cheki_exporter\
├── receipts.db   # чеки, товары, ручные покупки, возвраты и токены
├── settings.db   # категории и правила
└── sync.log      # журнал синхронизации
```

Для резервной копии закройте программу и скопируйте этот каталог. Личные базы, токены и отчёты не включаются в репозиторий и релиз. Excel-шаблон содержит только оформление и диаграммы без истории покупок.

## Синхронизация по расписанию

Из каталога исходников с установленными зависимостями:

```powershell
python sync.py
python sync.py --days 30
python sync.py --from 2024-01-01 --to 2024-03-31
```

`install_task.bat` устанавливает ежедневную синхронизацию в **20:00** по времени Windows. Нужны исходники и Python; одной GUI-сборки недостаточно. Проверяйте `sync.log`, если авторизация истекла.

## Проверка и сборка

```powershell
python -m pip install -r requirements.txt pyinstaller
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm moi_cheki_exporter.spec
```

Результат: `dist/MoiCheki.exe`. Можно запустить `build.bat`. Персональные базы и настройки не добавляются в сборку.

GitHub Actions выполняет тесты на Windows и при публикации тега `v*` собирает архив для релиза.

## Ограничения

Независимый инструмент, не официальный продукт ФНС или Ozon. Доступ зависит от их интерфейсов и действительности токенов. Категории определяются вашими правилами; без настроек часть расходов останется без категории. Продуктовый дашборд и общая статистика сохраняют существующее исключение отмеченных дубликатов и авансовых чеков.

В сообщении об ошибке укажите версию, действия и текст ошибки. Не прикладывайте токены, базы или реальные чеки.
