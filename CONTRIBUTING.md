# Работа с проектом

1. Создайте отдельную ветку для изменения.
2. Установите зависимости из `requirements.txt`.
3. Используйте синтетические чеки и временные базы.
4. Выполните `python -m unittest discover -s tests -v`.
5. Для изменений интерфейса проверьте вкладки и сообщения вручную.
6. Опишите проблему, новое поведение и проверки в pull request.

Не коммитьте базы, токены, отчёты, JSON личного кабинета или личные данные. Excel-шаблон должен содержать только оформление и диаграммы без покупок.

Версии фиксируются в `CHANGELOG.md`; тег имеет вид `v1.1.0`. Workflow собирает Windows x64 архив без пользовательских настроек.
